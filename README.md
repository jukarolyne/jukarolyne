### Projetos em Destaque

#### 🏨 [Hostify](https://github.com/dsnato/dsi-ufrpe)
Aplicativo de **reservas hoteleiras** com modelo de Machine Learning integrado para **previsão de cancelamentos**.

- Modelagem preditiva com Python + Scikit-learn
- Interface desenvolvida com React e Typescript
- Pipeline de dados com Pandas e SQL
- Problema real com impacto direto em gestão de receita

Programa para otimizar a fila de merenda escolar, com o objetivo de tornar justa a organização dos estudantes.

- Otimização utilizando Algoritmo Húngaro
- Criação de escalas semanais de merenda
- Planilha com registro de posições já ocupadas por cada turma
- Definição de prioridade de turmas
- Resolução de Problema de Atribuição
